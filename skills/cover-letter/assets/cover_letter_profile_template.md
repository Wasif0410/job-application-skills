# Cover letter profile

The `cover-letter` skill reads this file (and the Identity section of `tailor-profile.md`) on every run. Edit it to change how your letters look and sound. Only things you've said go in here; the skill never records its own choices as your preferences.

## Header (after the name + contact line), in this exact format
```
<Mon D, YYYY>                         (today's date)
Start Availability: <Month> <YYYY>    (default; always a month AND a year; must match the posting)
<length only>                         (default, e.g. 4/8/12 months; must match the posting)
Dear Hiring Manager,
```
- Company/recipient address block: no
- If a posting's term differs from the default, use the posting's term in the same format (e.g. "Start Availability: September 2027" / "4 months"). Line 3 is only a length, never a sentence.

## Sign-off
```
Sincerely,
<Your Name>
```

## Structure: five paragraphs in this order, about 430–500 words, one page
| # | Paragraph | Words | Notes |
|---|---|---|---|
| 1 | Hook about the company | 65–80 | Role, location, term + one company detail tied to something you built |
| 2 | Technical background | 90–110 | "My technical background aligns closely with <Company>'s <area> work." Then your relevant languages and tools, any related coursework, and what you build in your current role. No stories or metrics (those go in 4). |
| 3 | One project | 100–120 | Opens "I built <Project>, …" |
| 4 | Work experience (most important) | 160–180 | One job in depth, others one sentence each; ends with curiosity about the company's users |
| 5 | Goodbye | 2 sentences | "Thank you for your time and consideration." + "I'd welcome the chance to discuss how I could contribute to <Company>, and you can reach me at <email> or <phone>." |

## How to introduce each employer
| Employer | Intro |
|---|---|
| <Current employer> | "In my current role as a <title> at <Employer>, …" |
| <Past employer> | "During my previous internship as a <title> at <Employer>, …" |
