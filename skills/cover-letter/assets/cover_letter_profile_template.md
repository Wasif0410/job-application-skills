# Cover letter profile

The `cover-letter` skill reads this file (and the Identity section of `tailor-profile.md`) on every run. Edit it to change how your letters look and sound. Only things you've said go in here; the skill never records its own choices as your preferences.

## Header (after the name + contact line), in this exact format
```
<Mon D, YYYY>                         (today's date)
Start Availability: <Month> <YYYY>    (default; always a month AND a year; must match the posting)
<length only>                         (default, e.g. 4/8/12 months; must match the posting)
Dear Hiring Manager,
```
- Company/recipient address block: no
- If a posting's term differs from the default, use the posting's term in the same format (e.g. "Start Availability: September 2027" / "4 months"). Line 3 is only a length, never a sentence.

## Sign-off
```
Sincerely,
<Your Name>
```

## Structure: five paragraphs in this order, about 420–480 words, one page
| # | Paragraph | Words | Notes |
|---|---|---|---|
| 1 | Hook about the company | 70–80 | Role, location, term + one company detail tied to something you built |
| 2 | Technical skills | ~60 | Only your own skills, each tied to where you used it. No mention of the posting or company. |
| 3 | One project | 110–130 | Opens "I built <Project>, …" |
| 4 | Work experience (most important) | 170–190 | One job in depth, others one sentence each; ends with curiosity about the company's users |
| 5 | Goodbye | ≤35, 2 sentences | Thanks (+ one logistics fact if relevant), then contact details. No employer names. |
